    Field guide: why a standalone-file atlas

    A longer note for the people who decide whether tools like this get adopted or assigned — scroll within the frame below.

    For policy and procurement teams

    Standalone files outlast platforms

    Every page here is one HTML file with its CSS and JavaScript already inside it. There is no build step, no subscription, no vendor account and no server that can be discontinued out from under a classroom or a field office. A copy saved today should still open in ten years, offline, because nothing outside the file is required to run it.

    That is a deliberate procurement property, not an accident: institutions that need a tool to keep working after a grant ends, a contract lapses or a connection drops — government offices, schools, field researchers — benefit from software with no ongoing dependency left to fail.

    For teachers and students

    Every page includes its own real, runnable source — open “Inspect the exact JavaScript” on any page to read exactly what it does, with nothing hidden. Use a lab as a live example in class, or hand a student the AI upgrade prompt and have them extend it as an assignment. The constellation above can track a class’s progress locally, with nothing about them sent anywhere.
