New here? Start in three easy steps

1. Pick a starting point

Follow a learning path made for people like you, or open any page that sounds useful. Press Ctrl K (or ⌘ K) to search everything, including the meaning of technical words.

2. Try the real thing

Every topic lab has a live demonstration and every tool really works. Nothing you type leaves your device, and each page explains itself in plain language first.

3. Keep what you learn

Mark pages complete, write private notes, and download your progress whenever you like. Use Comfort settings (the sliders icon) for themes, calmer motion, larger text and more.

Works anywhere

Open the files straight from your computer, put them on a USB stick, or host them. Once a page is open it keeps working without a connection.

Learning paths

Guided routes through the atlas for different people. Follow one and every page on it will show you where you are and what comes next. You can switch or stop at any time; your progress is kept either way.

Glossary

Plain-language meanings for the technical words used in the atlas. Each term links to a page where you can try it.

Accessibility
Designing so people with different bodies, senses and minds can all use something: by keyboard, screen reader, voice, magnification or simply on a tired day. Try it: Accessibility & inclusive design
Agent (AI agent)
Software that plans and carries out several steps toward a goal. Safe agents ask a person before doing anything that changes data or costs money. Try it: AI agent architecture
Alt text
A short written description of an image, read aloud by screen readers and shown if the image cannot load. Decorative images get empty alt text so they are skipped. Try it: Accessibility & inclusive design
API
A set of ready-made commands one program offers another. Browsers offer APIs for storage, sound, location and more, so pages do not have to build those from scratch. Try it: JavaScript application architecture
ARIA
Extra HTML attributes that tell assistive technology what a custom control is and what state it is in. The first rule of ARIA: use a native HTML element instead whenever one exists. Try it: HTML attributes & smart interfaces
Backup (export)
A copy of your data saved as a file you control. Browser storage can be cleared, so exporting a backup is the only sure way to keep records long term. Try it: File import/export
Baseline
The first measurement you compare later ones against, such as plant counts before restoration began. Without a baseline you cannot say what changed. Try it: Restoration monitoring dashboard
BroadcastChannel
A browser feature that lets open tabs of the same site send each other messages instantly, without any server. Try it: Real-time collaboration
Cache
A stored copy of something fetched earlier, kept so it can be shown again quickly or without a connection. Try it: Progressive Web Apps
Canvas
An HTML element that scripts can paint on pixel by pixel. Used for charts, image editing and animation. Because it is just pixels, it needs a text alternative. Try it: GPU & graphics
Carbon intensity
How much carbon dioxide is released to produce one unit of electricity where you are. It changes by country, season and hour, so energy estimates should let you set it. Try it: Sustainable, low-carbon web design
Circuit breaker
A pattern that stops calling a failing service for a while after repeated errors, giving it time to recover instead of piling on more requests. Try it: Reliability & fault tolerance
Consent
A clear, informed, freely given yes that can be withdrawn at any time. Real consent is specific, never assumed from silence and never bundled into something else. Try it: Privacy engineering
Container query
A CSS rule that adapts a component to the space its container gives it, rather than to the whole screen, so the same card works in a sidebar and a main column. Try it: Responsive CSS layout systems
Content Security Policy (CSP)
A rule a page gives the browser listing where it may load or send things from. Every atlas page uses one to block connections to other websites. Try it: Web security
Contrast ratio
How different two colours are in brightness, from 1:1 to 21:1. Body text needs at least 4.5:1 against its background to be readable for most people. Try it: Advanced visual styling
CSV
A plain text table format that any spreadsheet can open. Each line is a row and commas separate the columns. Try it: Portable dataset explorer
Custom element
Your own HTML tag, such as <seed-card>, defined once in JavaScript and reusable anywhere on a page with its behaviour built in. Try it: Web Components & reusable elements
Data minimization
Collecting only the data you truly need, for a stated purpose, and deleting it when that purpose ends. Data you never collect can never leak. Try it: Privacy impact workbench
Dialog (modal)
A box that appears over the page and asks for attention. The native <dialog> element handles keyboard focus and the Escape key for you. Try it: Native interactive HTML
Digest (hash)
A short fingerprint calculated from data. Change one character and the fingerprint changes completely, so it reveals tampering, but it cannot tell you whether the content is true. Try it: Integrity & provenance
Encryption
Scrambling data so only someone with the right key can read it. It protects privacy when files are stored or shared. Try it: Cryptography & authentication
Exponential backoff
Waiting longer after each failed attempt (for example 1, 2, then 4 seconds) before trying again, so a struggling connection is not flooded. Try it: Reliability & fault tolerance
Feature detection
Checking whether the browser supports something before using it, then offering a simpler path if it does not. Try it: Progressive Web Apps
Focus (keyboard focus)
The element that will respond to the keyboard right now, usually shown with an outline. Moving focus in a sensible order is essential for keyboard users. Try it: Accessibility & inclusive design
GeoJSON
A common text format for map features. Points are written longitude first, then latitude, which trips up many people. Try it: Geospatial GIS
Great-circle distance
The shortest distance between two points on a sphere, measured over the surface. It ignores roads and terrain, so it is not a travel route. Try it: Geographic observation notebook
Hallucination (AI)
When an AI system states something fluent and confident that is not supported by any source. Citations and "I don't know" answers are the antidote. Try it: Retrieval-augmented generation
Human in the loop
A design where a person reviews and approves important steps an automated system proposes, instead of letting it act alone. Try it: AI agent architecture
IndexedDB
A database built into every modern browser. It holds much more than localStorage and works offline, but data stays on that one device. Try it: Local data storage
Intl
The browser's built-in tool for writing dates, numbers, currencies and lists the way people expect in each language and region. Try it: Internationalization & localization
JSON
A simple text format for structured data, readable by people and by almost every programming language. Atlas backups are JSON files. Try it: File import/export
JSON-LD
A way to describe a page's content (an article, an event, an organisation) in JSON so search engines and other tools can understand it. Try it: Search discovery & metadata
Landmark
A major area of a page, such as navigation or main content. Screen-reader users jump between landmarks the way sighted people glance around. Try it: Semantic HTML & document architecture
Live region
Part of a page that screen readers announce when its text changes, so a status like "Saved" is heard without moving focus. Try it: Accessibility & inclusive design
Local-first
Software that keeps your data on your own device first and works without a connection. Syncing or sharing is optional, never required. Try it: Offline-first functionality
localStorage
A small, simple place in the browser to keep text between visits. Quick to use, limited in size, and can be cleared by the browser or the person. Try it: Local data storage
Manifest (web app)
A small file that tells the browser a site's name, icons and colours, so it can be installed like an app. Try it: Progressive Web Apps
Metadata
Information that describes content: its title, author, date, licence or language. Good metadata helps people and tools find and trust things. Try it: Search discovery & metadata
Mutual aid
Neighbours meeting each other's needs through voluntary, reciprocal help, rather than charity from above. Offers and needs are shared as equals. Try it: Mutual aid offers & needs board
Nonviolent Communication (NVC)
A way of speaking that separates what happened from judgement, names feelings and needs, and makes requests the other person is free to decline. Try it: Compassionate message studio
Offline-first
Designing a tool to work fully without a connection, then using the network only as a bonus when it is there. Try it: Offline-first functionality
OKLCH
A way of describing colour by lightness, intensity and hue that matches human perception, which makes even, accessible colour scales easier to build. Try it: Advanced visual styling
Origin
The combination of scheme, host and port (like https://example.org). Browsers keep each origin's data and permissions separate for safety. Try it: Web security
Page weight
How much data a page makes a device download. Lighter pages load faster on weak connections and use less energy. Try it: Sustainable, low-carbon web design
Permission prompt
The browser's own question before a site can use sensitive things like location, camera or microphone. Good sites only ask after you choose an action that needs it. Try it: Device sensors & permissions
Progressive enhancement
Building a page that works in the simplest browser first, then adding richer features only where they are supported. Try it: Semantic HTML & document architecture
Provenance
Where something came from and what happened to it since: who made it, when, from what sources, and who changed it. Try it: Evidence provenance ledger
PWA (progressive web app)
A website that can be installed, opened from the home screen and used offline, built with ordinary web technology. Try it: Progressive Web Apps
RAG (retrieval-augmented generation)
Answering questions by first finding relevant passages in trusted documents, then answering only from those passages with citations. Try it: Retrieval-augmented generation
Reduced motion
A device setting people use when animation causes dizziness, nausea or distraction. Respectful sites tone down or remove motion when it is on. Try it: Animation & cinematic interfaces
Schema
An agreed shape for data: which fields exist, what type each is, and which are required. Checking a schema stops broken files from corrupting your records. Try it: File import/export
Screen reader
Software that reads the screen aloud or to a braille display, used by many blind and low-vision people. It relies on good HTML structure. Try it: Accessibility & inclusive design
Secure context (HTTPS)
A page delivered over an encrypted connection (or from your own computer). Many powerful browser features only work in secure contexts. Try it: Hosting & deployment
Semantic HTML
Using HTML elements for what they mean (a heading, a list, a button) rather than how they look, so browsers and assistive tools understand the page. Try it: Semantic HTML & document architecture
Service worker
A small script a site installs in your browser that can save pages and serve them when you are offline. Try it: Progressive Web Apps
Shadow DOM
A private inner structure for a web component, with its own styles that do not leak in or out. Try it: Web Components & reusable elements
SVG
Pictures described as shapes and text in code, so they stay sharp at any size and can be read and labelled for accessibility. Try it: Visual knowledge navigation
Uncertainty (measurement)
How far a measured value might be from the true value, written like 7.2 ± 0.3. Honest data always says how sure it is. Try it: Environmental monitoring
View Transitions
A browser feature that animates smoothly between two states of a page, or between pages, instead of jumping. Try it: Animation & cinematic interfaces
WCAG
The international guidelines for accessible web content, organised as testable success criteria at levels A, AA and AAA. Try it: Accessibility & inclusive design
Web Audio
A browser feature for generating, mixing and analysing sound in real time, entirely on your device. Try it: Audio & video production
Web Worker
A script that runs in the background, separately from the page, so heavy work does not freeze buttons and scrolling. Try it: Background threads & WebAssembly
WebAssembly
A compact, fast format for running compiled code (from languages like Rust or C) safely inside the browser alongside JavaScript. Try it: Background threads & WebAssembly
WebGL and WebGPU
Browser features that use a device's graphics hardware for fast drawing and computation. Always provide a simpler fallback. Try it: GPU & graphics
WebXR
A browser feature for virtual and augmented reality experiences on supported headsets and phones. Try it: Spatial interfaces
XSS (cross-site scripting)
An attack where text someone typed is treated as code by a page. Showing untrusted text with textContent instead of innerHTML prevents it. Try it: Web security

Field guide: why single-file tools

A longer note for people who decide which tools get adopted or assigned. Scroll inside the frame.

For policy and procurement teams

Standalone files outlast platforms

Every page here is one HTML file with its styles and scripts inside. There is no build step to run it, no subscription, no vendor account and no server that can be discontinued under a classroom or a field office. A copy saved today should still open years from now, offline, because nothing outside the file is needed.

That is a deliberate property, not an accident. Schools, field researchers and public offices need tools that keep working after a grant ends, a contract lapses or a connection drops.

For teachers and students

Every page shows its own source under “Look under the hood”, so nothing is hidden. Use a lab as a live example in class, or give a student its AI prompt and ask them to extend it and check the result. A learning circle can track a group's progress with nothing about anyone sent anywhere.

How this atlas is built and checked

Built to last

Each page carries its own design system and code, so it works alone. A small build tool in the download keeps the shared parts identical across pages and regenerates the catalog, offline list and checksums. Every page also carries a privacy lock that tells your browser to refuse connections to any other website.

Checked, honestly

Releases are tested in a real browser: every page loads without errors, every button is pressed, an automated accessibility scan runs, and offline use is verified. Automated checks catch only part of what matters, so the testing notes say plainly what was and was not checked.
